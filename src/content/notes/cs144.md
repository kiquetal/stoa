CS144 is a rebuild-it-to-understand-it course. Rather than memorizing the OSI
model, you implement a functioning TCP stack over a lab-provided datagram
interface.

## The end-to-end principle

The core architectural argument: functions like reliability and ordering are
best implemented **at the endpoints**, not in the network fabric. The network
should be a simple, best-effort datagram mover.

## Transport lab notes

Reassembling a reliable byte stream from out-of-order segments comes down to a
`StreamReassembler` that:

- buffers segments beyond the current window
- writes contiguous bytes to the output stream as gaps fill
- tracks the first unassembled index as the ack pointer

```cpp
// core invariant
first_unassembled <= first_unacceptable;
capacity == bytes_in_flight + available_window;
```
